# Changelog

`CHANGELOG.md` is the extension's release notes, and roam.pub shows it at `/updates` (What's new) next to the website's; nothing there is generated from commits. Every change users would notice adds a bullet in the same commit, under `## Unreleased` (dated by the file's last commit on `main`) and a `### Area` (reuse one: Commands, Status link and change log, Publishing, Setup and settings…). A release renames `## Unreleased` to `## x.y.z (YYYY-MM-DD)`. Write for the people who use the extension, one change per bullet, wrapped lines indented. Leave out tests, refactors, build tooling and fixes too small to notice. The Changelog check fails a PR into `main` that changes `src/` without touching `CHANGELOG.md`; label it `no-changelog` when there's genuinely nothing to log.
